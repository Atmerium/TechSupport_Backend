
## Description

Backend repo for the Techsupport project

## Project setup

```bash
$ npm install
$ npx prisma generate
$ npx prisma db push
$ npx tsx .\prisma\seeder.ts
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Url for API documentation

```bash
# API documentation
$ localhost:3000/api
```
